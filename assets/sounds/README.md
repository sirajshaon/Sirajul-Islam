# assets/sounds/

Place your audio greeting file here:

## Required file
**salaam.mp3** — A soft, respectful male Arabic voice saying "Assalamu Alaikum"

## Specifications
- Format : MP3 (preferred) or OGG
- Duration: 3–5 seconds
- Volume  : Record at moderate level (code sets volume to 28%)
- Tone    : Calm, respectful, warm

## Where to get it
- Record your own using a microphone
- Use a text-to-speech service with Arabic voice
- Download from a reputable Islamic audio library (ensure license allows use)

## How it works
- Plays **once per browser session** (not on every page visit)
- Only on the **homepage** (index.html)
- User can mute/unmute with the 🔊 button (bottom-right corner)
- If the file is missing, the site works normally with no error shown
