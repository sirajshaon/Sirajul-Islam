অ্যাকাউন্ট ও ক্লাউড সিঙ্ক চালু করার নিয়ম (একবারই করতে হবে, সময় ১০-১৫ মিনিট)
=====================================================================
খরচ: ০ টাকা। Firebase এর "Spark" ফ্রি প্ল্যান, কার্ড লাগে না।
যদি কখনো "Upgrade" বা "Blaze plan" বা কার্ড চায়, তাহলে চাপবেন না। এই অ্যাপের জন্য দরকার নেই।

ধাপ ১: প্রজেক্ট বানান
  1. ব্রাউজারে console.firebase.google.com খুলুন, Gmail দিয়ে লগইন করুন।
  2. "Create a project" (বা "Add project") চাপুন।
  3. নাম দিন: taka-journal  -> Continue
  4. Google Analytics চাইলে বন্ধ (disable) করে দিন -> Create project
  5. তৈরি হলে Continue চাপুন।

ধাপ ২: ইমেইল-পাসওয়ার্ড লগইন চালু করুন
  1. বাঁ পাশের মেনুতে Build -> Authentication -> "Get started"
  2. "Sign-in method" ট্যাবে Email/Password চাপুন
  3. প্রথম Enable সুইচটা চালু করুন (দ্বিতীয়টা না) -> Save

ধাপ ৩: ডাটাবেস বানান
  1. Build -> Firestore Database -> "Create database"
  2. Location: যেকোনো কাছের (যেমন asia-south1) -> Next
  3. "Start in production mode" বেছে নিন -> Create

ধাপ ৪: নিরাপত্তা নিয়ম বসান (খুব জরুরি)
  1. Firestore Database পেজে "Rules" ট্যাবে যান।
  2. সব লেখা মুছে নিচের লেখাটি পেস্ট করুন, তারপর "Publish" চাপুন:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

  (এই নিয়মের মানে: প্রত্যেকে শুধু নিজের ডাটা দেখতে ও লিখতে পারবে, অন্য কেউ পারবে না।)

ধাপ ৫: দুটি তথ্য কপি করুন
  1. বাঁ পাশে উপরে Project Overview এর পাশের গিয়ার (⚙) -> "Project settings"
  2. General ট্যাবে নিচে "Your apps" এ Web আইকন  </>  চাপুন
  3. App nickname: taka-journal -> "Register app"  (Hosting বক্সে টিক দেবেন না)
  4. যে কোড দেখাবে তাতে apiKey এবং projectId লেখা থাকবে। ওই দুটি মান কপি করুন।
     (এগুলো গোপন পাসওয়ার্ড না। সুরক্ষা আসে ধাপ ৪ এর নিয়ম থেকে।)

ধাপ ৬: অ্যাপে বসান
  1. এই ফোল্ডারের firebase-config.js ফাইলটি নোটপ্যাড দিয়ে খুলুন।
  2. apiKey: "" এর কোটেশনের ভেতরে apiKey, আর projectId: "" এর ভেতরে projectId বসান।
  3. সেভ করুন। তারপর GitHub এ ওই একটা ফাইল আপলোড করে আগেরটা প্রতিস্থাপন করুন।
     (অ্যাপের নতুন ফাইলগুলোও GitHub এ আপলোড করতে হবে।)

ধাপ ৭: ব্যবহার
  1. অ্যাপ খুলে More -> Account & sync -> ইমেইল ও পাসওয়ার্ড দিয়ে "Create account"।
  2. আপনার এই ডিভাইসের আগের ডাটা নিজে থেকে অ্যাকাউন্টে উঠে যাবে।
  3. অন্য ডিভাইসে একই ইমেইল-পাসওয়ার্ড দিয়ে "Sign in" করুন। ডাটা চলে আসবে।
  4. এরপর থেকে কিছু যোগ বা বদলালে কয়েক সেকেন্ডে নিজে থেকে সিঙ্ক হয়।
     ইন্টারনেট না থাকলে ডিভাইসেই সেভ থাকে, নেট এলে সিঙ্ক হয়।

জেনে রাখুন
  - Sign out করলে ওই ডিভাইসের ডাটা মুছে যায় (অ্যাকাউন্টে থাকে)। অন্যের হাতে ফোন গেলেও হিসাব সুরক্ষিত থাকে।
  - পাসওয়ার্ড ভুলে গেলে Forgot password চাপুন, ইমেইলে লিংক যাবে।
  - দুই ডিভাইসে একই সময়ে একই খরচ বদলালে যেটা পরে সেভ হয়েছে সেটা থাকে।
  - ক্যাটাগরি, বাজেট, পেমেন্ট পদ্ধতির সেটিংসেও একই নিয়ম: যে ডিভাইসে শেষে বদলানো হয়েছে সেটাই থাকে।
  - তবু মাঝে মাঝে More থেকে ব্যাকআপ ডাউনলোড করে রাখা ভালো।
  - ফ্রি প্ল্যানের সীমা (দিনে ৫০,০০০ রিড, ২০,০০০ রাইট) ব্যক্তিগত ব্যবহারের জন্য অনেক বেশি।
